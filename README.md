# Trabalho-de-Extensão-de-Tópicos-de-Big-Data-em-Python

# Evolução da Infraestrutura Tecnológica nas Escolas de Educação Básica

## Sobre o projeto

Este projeto foi desenvolvido como parte da disciplina de Tópicos em Big Data, com o objetivo de analisar a evolução da infraestrutura tecnológica das escolas de educação básica nos municípios de Niterói e São Gonçalo, no estado do Rio de Janeiro.

A pesquisa utiliza dados do Censo Escolar, disponibilizados pelo Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira (INEP), referentes aos anos de 2022, 2023 e 2024. A partir desses dados, buscamos compreender como os recursos tecnológicos disponíveis nas escolas evoluíram ao longo do período analisado e identificar possíveis avanços, estagnações ou retrocessos na infraestrutura educacional.

## Objetivo

O principal objetivo do projeto é analisar e comparar a infraestrutura tecnológica das escolas de educação básica de Niterói e São Gonçalo, observando a disponibilidade de recursos relacionados à conectividade, equipamentos e estrutura tecnológica.

Além da análise técnica, o trabalho busca contribuir para a reflexão sobre a inclusão digital no ambiente escolar e sobre a importância de uma infraestrutura adequada para acompanhar as demandas de uma sociedade cada vez mais conectada.

## Dados analisados

Foram utilizados microdados do Censo Escolar dos anos de 2022, 2023 e 2024, considerando escolas dos municípios de Niterói e São Gonçalo.

Os indicadores de infraestrutura analisados foram:

- Acesso à internet na escola;
- Acesso à internet para os alunos;
- Internet banda larga;
- Disponibilidade de computadores;
- Laboratório de informática;
- Biblioteca;
- Quadra de esportes.

## Metodologia

O projeto foi desenvolvido utilizando Python no Google Colab, seguindo etapas de obtenção, extração, seleção, limpeza, organização e análise dos dados.

Após o tratamento das bases, foram realizadas comparações entre os anos e os municípios selecionados, utilizando cálculos estatísticos e visualizações gráficas para facilitar a interpretação dos resultados.

Entre os métodos utilizados estão:

- Estatística descritiva;
- Cálculo de médias e percentuais;
- Desvio padrão;
- Identificação de outliers utilizando o método IQR (Intervalo Interquartil);
- Regressão Linear Simples para análise de tendências ao longo dos anos;
- Gráficos comparativos para visualização dos resultados.

## Ferramentas e tecnologias

- **Python:** linguagem utilizada no desenvolvimento e processamento dos dados.
- **Google Colab:** ambiente utilizado para execução do código.
- **Pandas:** manipulação, filtragem, organização e análise das bases de dados.
- **NumPy:** suporte para operações e cálculos numéricos.
- **Matplotlib:** criação dos gráficos e visualizações.
- **Scikit-learn:** aplicação da Regressão Linear Simples.
- **gdown:** ferramenta utilizada para facilitar o acesso e download dos arquivos armazenados no Google Drive.

## Resultados e importância social

A análise permitiu observar diferenças entre a disponibilidade de infraestrutura tecnológica nas escolas, destacando que a presença de internet na instituição não significa necessariamente que os alunos tenham acesso direto a esse recurso para fins educacionais.

Também foram observados sinais de estagnação ou redução em determinados recursos tecnológicos ao longo do período analisado, como os laboratórios de informática, reforçando a importância de acompanhar não apenas a conectividade das instituições, mas também a disponibilidade de equipamentos e recursos que possam contribuir para o aprendizado.

O projeto busca demonstrar como a análise de dados pode ser utilizada para compreender problemas reais, transformar informações públicas em resultados acessíveis e estimular discussões sobre inclusão digital e infraestrutura tecnológica na educação.

## Conclusão

A realização deste trabalho proporcionou a aplicação prática de conceitos de Big Data e análise de dados, desde o tratamento de bases públicas até a utilização de métodos estatísticos para interpretar informações e identificar tendências.

Além do aprendizado técnico, o projeto evidencia a importância da análise de dados como ferramenta para investigar questões sociais e contribuir para uma melhor compreensão da realidade educacional.
